# 在线游戏中心 (AI Game Platform)

完全由AI生成的包含多个经典网页小游戏的在线游戏中心。本项目已重构为成熟的游戏平台，提供统一的入口、导航和视觉体验。

## 游戏列表

目前包含以下游戏：

*   **Flappy Bird**: 控制小鸟穿过管道。
*   **德州扑克**: 与 AI 对战的经典扑克游戏。
*   **贪吃蛇**: 控制小蛇吃食物变长。
*   **森林冰火人**: 双人合作平台闯关游戏。
*   **拳皇**: 经典的街机格斗游戏。

## 平台特性

*   **统一入口**: 现代化的游戏大厅，支持搜索和主题切换。
*   **无缝导航**: 所有游戏内置统一的导航条，方便随时返回大厅。
*   **响应式设计**: 适配桌面和移动设备。
*   **模块化架构**: 公共资源分离，易于维护和扩展。

## 如何玩

您可以直接访问在线版本来玩这些游戏：

[https://TingjiaInFuture.github.io/](https://TingjiaInFuture.github.io/)

## 技术栈

*   HTML5
*   CSS3 (Flexbox, Grid, Animations)
*   JavaScript (ES6+)

## 目录结构

*   `platform/`: 平台公共资源 (CSS, JS)
*   `firewater/`, `flappybird/`, etc.: 独立游戏模块
*   `index.html`: 平台入口
